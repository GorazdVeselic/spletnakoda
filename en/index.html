FAQ

Frequently asked questions

What is Spletna koda?

Spletna koda is the independent development practice of Gorazd Veselič, a senior full-stack / DevOps engineer with more than 20 years of experience. It focuses on backend architecture, API and B2B integrations, and cloud infrastructure.

Can you connect our system to external systems?

Yes. I design and build REST APIs, B2B integrations with external systems (e.g. ERPs, online shops, suppliers) and microservices that automate business processes and remove manual data re-entry.

Do you help with cloud migration and DevOps?

Yes. I set up and maintain infrastructure on AWS, containerize applications with Docker and run them on Kubernetes, describe infrastructure as code with Terraform, and introduce CI/CD for automated, repeatable deployments.

Which technologies do you work with?

Backend: PHP, Laravel, MySQL, Redis and REST APIs. Infrastructure: Docker, Kubernetes, AWS, Terraform, CI/CD and Linux. Frontend: Vue and Next.js.

Do you take over maintenance of existing applications?

Yes. I take over existing Laravel/PHP applications, optimize slow databases, set up stable hosting and handle ongoing maintenance.

How do we start working together?

Email gorazd@spletnakoda.si with a short description of your project or problem. I work in Slovenian and English.
